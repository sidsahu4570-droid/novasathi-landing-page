This folder stores customer review video testimonials.

== HOW TO ADD REAL VIDEOS ==

1. Drop the MP4 files here:
   - review-1.mp4  → Rahul  (Career & Astrology)
   - review-2.mp4  → Tanvi  (Love & Relationships)
   - review-3.mp4  → Rohan  (Tarot & Guidance)

2. Optionally add WebM versions for better browser compatibility:
   - review-1.webm
   - review-2.webm
   - review-3.webm

3. To add a poster (thumbnail) image for each video, add:
   - review-1-poster.jpg
   - review-2-poster.jpg
   - review-3-poster.jpg

4. To update testimonial data (name, category, quote, video path),
   edit the testimonials array in:
   src/components/landing/VideoTestimonials.jsx

Recommended video specs:
- Format: MP4 (H.264)
- Resolution: 720p (1280x720) or 1080p
- Duration: 30–90 seconds
- Aspect ratio: 16:9
- Max size: 30MB per video (for web performance)
